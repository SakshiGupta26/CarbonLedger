# 🌱 CarbonLedger

### A Modern Web3 Carbon Credit Platform

CarbonLedger is a modern frontend application designed for a blockchain-powered carbon credit ecosystem. The platform provides an intuitive interface for exploring digital carbon credits, monitoring a user's carbon credit portfolio, and understanding the lifecycle of tokenized environmental assets.

The project focuses on combining **Web3 concepts, sustainability, and modern frontend engineering** to create a clean and scalable user experience for digital carbon markets.

---

## 🚀 Live Demo

🔗 **Live Application:**  
https://carbon-ledger-j3yt.vercel.app/

---

## 📌 Project Overview

Carbon credits are increasingly being represented as digital assets to improve transparency, traceability, and accessibility in environmental markets.

CarbonLedger provides a user-friendly interface for interacting with this ecosystem.

The application includes:

- Carbon credit marketplace
- Digital credit information
- Portfolio management
- User dashboard
- Carbon credit statistics
- Credit lifecycle visualization
- Modern Web3-inspired interface
- Responsive design

The frontend is structured to be easily extendable with blockchain smart contracts, wallet integrations, and backend services in the future.

---

## ✨ Key Features

### 🌿 Carbon Credit Marketplace

Explore available carbon credits and their associated environmental information through a clean marketplace interface.

### 📊 Portfolio Dashboard

Users can view their carbon credit holdings and monitor important portfolio statistics from a centralized dashboard.

### 🔗 Digital Asset Concept

The interface is designed around the concept of carbon credits represented as digital assets on a blockchain.

### 📈 Portfolio Statistics

The dashboard provides users with important information such as:

- Total carbon credits
- Portfolio value
- Environmental impact
- Credit ownership

### 🔄 Credit Lifecycle

The application visually represents the lifecycle of a digital carbon credit, helping users understand how credits can move through different stages.

### 👤 User Profile

A dedicated user section provides a clear overview of the user's account and carbon credit activity.

### 📱 Responsive Interface

The application is designed to provide a consistent experience across desktop and smaller screen sizes.

### 🎨 Modern Web3 UI

A dark-themed interface with modern cards, dashboards, icons, spacing, and visual hierarchy inspired by contemporary Web3 applications.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/SakshiGupta26/CarbonLedger.git
```

### 2. Navigate to the Frontend

```bash
cd CarbonLedger/Frontent
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

* **Transparency**
* **Traceability**
* **Digital ownership**
* **Immutable records**

CarbonLedger explores how these concepts can be combined into a modern digital platform.
